# Recursos de GNS3 y automatización de redes

## 1. Objetivo

Identificar recursos técnicos que ayuden a comprender el uso de GNS3, el control de versiones y las bibliotecas utilizadas para automatizar tareas relacionadas con redes.

## 2. Recursos consultados

### Recurso 1. Documentación oficial de GNS3

- **URL:** https://docs.gns3.com/
- **Tema que aborda:** Uso y configuración del simulador de redes GNS3.
- **Tipo de información:** Guías, instrucciones y documentación sobre las funciones de la herramienta.
- **Utilidad para el proyecto integrador:** Ayuda a resolver dudas relacionadas con la creación de proyectos, el uso de dispositivos y la configuración del entorno de simulación.
- **Ejemplo de cuándo lo consultaría:** Si tengo dificultades para crear una topología o iniciar un dispositivo dentro de GNS3.

### Recurso 2. Documentación oficial de Git

- **URL:** https://git-scm.com/doc
- **Tema que aborda:** Control de versiones y administración de cambios en archivos.
- **Tipo de información:** Manuales y documentación sobre comandos y funciones de Git.
- **Utilidad para el proyecto integrador:** Permite comprender cómo registrar cambios, consultar versiones anteriores y sincronizar el trabajo con GitHub.
- **Ejemplo de cuándo lo consultaría:** Si necesito revisar el estado del repositorio, guardar cambios mediante un commit o solucionar un problema al sincronizar archivos.

### Recurso 3. Documentación de Netmiko

- **URL:** https://ktbyers.github.io/netmiko/
- **Tema que aborda:** Conexión y administración de dispositivos de red mediante Python.
- **Tipo de información:** Documentación de la biblioteca, ejemplos de uso y explicaciones sobre sus funciones.
- **Utilidad para el proyecto integrador:** Puede servir como referencia para futuras actividades de automatización que requieran establecer conexiones con dispositivos de red compatibles.
- **Ejemplo de cuándo lo consultaría:** Si en una práctica posterior necesito investigar cómo ejecutar comandos de administración en un router mediante un programa de Python.

## 3. ¿Qué tipo de problema se puede resolver con la documentación de GNS3?

Se pueden investigar problemas relacionados con la creación de proyectos, la configuración del entorno, el uso de dispositivos virtuales y el funcionamiento de las topologías. La documentación permite consultar los procedimientos recomendados para utilizar correctamente la herramienta.

## 4. Diferencia entre la documentación de una herramienta y el repositorio de una biblioteca

La documentación de una herramienta explica cómo utilizarla y configurar sus funciones. Por otro lado, el repositorio de una biblioteca normalmente contiene su código fuente, archivos del proyecto, ejemplos, versiones y reportes de problemas.

Los dos recursos se complementan, pero cumplen funciones diferentes. La documentación ayuda a aprender a utilizar la herramienta y el repositorio permite revisar el desarrollo de la biblioteca y consultar información técnica adicional.

## 5. ¿Qué información revisaría antes de utilizar una biblioteca de automatización?

Antes de utilizar una biblioteca, revisaría su documentación, los requisitos de instalación, las versiones compatibles, las plataformas que admite y los ejemplos disponibles. También comprobaría si sus funciones corresponden a las necesidades del proyecto.

## 6. ¿Por qué es importante comprobar qué plataformas y funciones admite una biblioteca?

Porque no todas las bibliotecas funcionan con los mismos dispositivos, sistemas operativos o versiones de software. Revisar esta información ayuda a evitar problemas de compatibilidad y permite seleccionar una herramienta apropiada para la tarea.

## 7. ¿Cómo podrían utilizarse estos recursos en las siguientes prácticas?

La documentación de GNS3 puede ayudar a mantener y comprender el entorno de simulación. Git permite organizar y registrar los cambios del proyecto, mientras que Netmiko puede servir como referencia para estudiar futuras tareas de automatización de dispositivos de red.

## 8. Conclusión

Consultar recursos técnicos confiables facilita la resolución de dudas durante el desarrollo de un proyecto. Cada recurso tiene una función diferente: GNS3 ayuda con la simulación, Git con el control de versiones y Netmiko con la automatización de dispositivos compatibles. Revisar sus instrucciones y requisitos antes de utilizarlos ayuda a trabajar de manera más organizada.
